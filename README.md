# Health Tracker — web version

A small app for logging how you felt each day: mood, energy, hours of sleep
and a note. One entry per day.

**Everything stays on your device.** There is no server, no account, and no
network request of any kind — entries live in your browser's own storage and
are never sent anywhere. That is also why this can simply be handed to someone
as a link: there is nowhere for anyone's data to be collected, because no such
place exists.

## Using it

Open the link on a phone or computer. Nothing to install.

**On a phone, add it to your Home Screen.** This matters more than it sounds:
iOS clears the stored data of websites left unopened for about a week, and an
installed app is exempt. On iPhone tap Share → *Add to Home Screen*; on Android
your browser will offer to install it.

**Save a backup now and then**, from the History tab. Browser storage is
convenient but not durable — clearing website data erases it, and so does
switching browser or phone. The backup file is the only copy that survives
that, and *Restore backup* reads it back on any device.

## What it does

- **Today** — rate mood and energy from 1 to 10, record hours of sleep, write
  a note. Every field is optional: "—" means *no answer*, which is stored
  differently from a low score so unanswered days never drag your averages
  down. You can change any of it later, including clearing a rating.
- **History** — every logged day; tap one to edit it, or delete it.
- **Trends** — mood and energy on a shared 1–10 chart, sleep on its own hours
  chart. Days you did not log leave a gap: the line is dotted across it rather
  than solid, so a break in your logging never looks like a steady trend.

## Running it locally

```
python3 serve.py
```

Serves this folder on port 8000 and prints an address you can open on a phone
on the same Wi-Fi. It disables caching, so a reload always shows your latest
edits — the default Python server does not, which costs a confusing half hour
the first time it bites.

No build step, no dependencies. It is HTML, CSS and one JavaScript file.

Icons are generated by `python3 make_icons.py` (standard library only) and
committed, so deploying needs nothing but the files here.

## Deploying

Any static host works. The repository root is the site, so GitHub Pages can
serve it directly from the `main` branch with no configuration.

When `app.js` or `style.css` change, bump the `?v=` number in `index.html` and
`CACHE_NAME` in `sw.js`. Both exist so a browser holding an old cached copy
cannot keep serving it after an update.
